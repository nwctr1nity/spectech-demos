# Демо-сайты аренды спецтехники

Один сайт на шаблоне «Экспресс БС», каждая фирма открывается по адресу `/s/<slug>/`.
Данные фирм лежат в `src/data.ts`: контакты, адрес, часы и рейтинг взяты из карточки 2ГИС, цены техники примерные.

- Новая фирма: добавить объект в `TENANTS` в `src/data.ts`.
- Фото техники: `public/photos/<lift|crane|excavator|loader|dump>.webp`.
- Все страницы закрыты от поисковиков (`noindex`), сверху плашка «Демо-версия».
- Деплой на Vercel: импортировать репозиторий как отдельный проект, корень репозитория, настраивать ничего не нужно.

После продажи: вынести фирму в отдельный проект без плашки и `noindex`, вставить её цены.
